# Lume Órbita — العربية

QA: [0.4.0](../../qa/i18n-validation.md) · [0.4.1](../../qa/konka-041-validation.md) · [0.4.2](../../qa/clock-locale-042.md)

مشغّل أصلي لأجهزة Android TV وGoogle TV بإصدار 11 أو أحدث. لا توجد شهادة توافق لكل الطرازات؛ سلوك Home والعودة من الاستعداد يعتمد على الشركة المصنّعة.

## اللغة والتحكم

من الإعدادات > اللغة، يتبع الاختيار التلقائي لغة التلفاز المدعومة ويستخدم en-US عند عدم توفرها. يمكن الاختيار يدويًا؛ تتغيّر لغة التطبيق وحده دون تغيير لغة النظام. رمز العربية ar، واتجاه الواجهة من اليمين إلى اليسار.

تنقّل بالأسهم واختر باستخدام OK وعد باستخدام رجوع. الضغط المطوّل على التطبيق يفتح إجراءاته. في المكتبة، يضيف OK التطبيق إلى المفضّلة أو يزيله؛ ويغيّر خيار النقل ترتيبه. تُحفظ الاختيارات محليًا. أسماء التطبيقات والمحتوى المشترك يقدّمها ناشروها.

## المظهر وشاشة التوقف

وضع السينما يعتّم المشغّل فقط. الجدول الاختياري من الثامنة مساءً إلى السادسة صباحًا يستخدم توقيت التلفاز المحلي ولا يغيّر إعدادات صورته. يتوفر فن إجرائي دون إنترنت. الصور عبر الإنترنت تبقى في ذاكرة التطبيق دون تخزين مؤقت على القرص؛ راجع نسب الصور في الإعدادات. يتحكم Android بشاشة التوقف خارج المشغّل وسكون التلفاز.

## التثبيت والتراجع

ثبّت APK عبر اتصال ADB مصرّح به فقط. سجّل مكوّن Home السابق، ثم تحقّق منه بعد التثبيت وتوقف عند تغيّر غير متوقع. تتطلب التحديثات الحزمة والشهادة نفسيهما؛ لا تمسح البيانات أو تلغِ التثبيت لتجاوز تعارض التوقيع. التثبيت وحده لا يجعل التطبيق Home الافتراضي.

اختبر التطبيق أولًا، ثم اختره من إعداد Home الرسمي إذا كان الجهاز يدعم ذلك. أبقِ مشغّلًا آخر متوافقًا مثبتًا. قبل إزالة Lume، اختر Home آخر يعمل واختبره بجهاز التحكم. لا حاجة إلى root أو تعديل البرنامج الثابت أو حذف تطبيقات النظام.

## البناء والتراخيص والتحقق

إذا عدّلت ملفات الترجمة JSON، فأعد توليد الموارد وتحقّق منها من جذر المستودع قبل تشغيل Gradle. يلزم Python 3.10 أو أحدث:

```sh
python tools/build_locale_resources.py
python tools/verify_locales.py
```

المتطلبات: JDK 17 وAndroid SDK 35 وBuild Tools 36.0.0. من src/android شغّل مهام wrapper: testDebugUnitTest وverifyRulesCoverage وassembleRelease وlintRelease؛ استخدم gradlew.bat في Windows. لا تنشر مسار SDK المحلي أو مفتاح التوقيع الخاص. قد يختلف توقيع بنائك عن توقيع APK الرسمي.
