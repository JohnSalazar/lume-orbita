# Lume Órbita — اردو

QA: [0.4.0](../../qa/i18n-validation.md) · [0.4.1](../../qa/konka-041-validation.md) · [0.4.2](../../qa/clock-locale-042.md)

Android TV اور Google TV 11 یا بعد کے نسخوں کے لیے اصل لانچر۔ تمام ماڈل کی مطابقت کی تصدیق نہیں ہوئی؛ Home اور اسٹینڈبائی سے واپسی کا رویہ بنانے والے پر منحصر ہے۔

## زبان اور ریموٹ

ترتیبات > زبان میں خودکار انتخاب ٹی وی کی معاون زبان اپناتا ہے؛ وہ دستیاب نہ ہو تو en-US استعمال ہوتی ہے۔ دستی انتخاب بھی ممکن ہے۔ صرف ایپ کی زبان بدلتی ہے، نظام کی نہیں۔ اردو کا ٹیگ ur-PK ہے اور انٹرفیس دائیں سے بائیں ہے۔

تیروں سے چلیں، OK سے منتخب کریں اور واپس کے بٹن سے لوٹیں۔ ایپ پر OK دبائے رکھنے سے کارروائیوں کا مینو کھلتا ہے۔ لائبریری میں OK سے پسندیدہ شامل یا خارج کریں؛ جگہ بدلیں سے ترتیب بدلیں۔ انتخاب مقامی طور پر محفوظ رہتا ہے۔ ایپس کے نام اور شیئر کردہ مواد ان کے ناشر فراہم کرتے ہیں۔

## ظاہری شکل اور اسکرین سیور

سنیما موڈ صرف لانچر کی روشنی مدھم کرتا ہے۔ اختیاری شیڈول ٹی وی کے مقامی وقت میں رات 8 سے صبح 6 بجے تک ہے؛ تصویر کی ترتیبات نہیں بدلتیں۔ آف لائن الگورتھم سے بنا فن دستیاب ہے۔ آن لائن تصاویر صرف ایپ کی میموری میں رہتی ہیں، ڈسک کیش میں نہیں۔ تصاویر کے حوالے ترتیبات میں دیکھیں۔ دیگر ایپس کے اسکرین سیور اور ٹی وی کی نیند Android کنٹرول کرتا ہے۔

## انسٹال، اپ ڈیٹ اور واپسی

صرف مجاز ADB کنکشن سے APK انسٹال کریں۔ پرانا Home جزو درج کریں، انسٹال کے بعد دوبارہ جانچیں اور غیر متوقع تبدیلی پر رک جائیں۔ اپ ڈیٹ کے لیے وہی پیکیج اور سرٹیفکیٹ ضروری ہے؛ دستخط کا اختلاف دور کرنے کے لیے ڈیٹا نہ مٹائیں اور اَن انسٹال نہ کریں۔ صرف انسٹال کرنے سے ایپ طے شدہ Home نہیں بنتی۔

پہلے ایپ آزمائیں، پھر ٹی وی کے سرکاری Home انتخاب میں منتخب کریں۔ دوسرا مطابقت رکھنے والا لانچر انسٹال رکھیں۔ Lume ہٹانے سے پہلے دوسرا فعال Home منتخب کر کے ریموٹ سے آزمائیں۔ root، فرم ویئر کی تبدیلی یا سسٹم ایپس حذف کرنا ضروری نہیں۔

## بلڈ، لائسنس اور جانچ

ترجمے کی JSON فائلیں بدلنے کے بعد، Gradle سے پہلے منصوبے کے بنیادی فولڈر سے وسائل دوبارہ بنائیں اور جانچیں۔ Python 3.10 یا بعد کا نسخہ درکار ہے:

```sh
python tools/build_locale_resources.py
python tools/verify_locales.py
```

JDK 17، Android SDK 35 اور Build Tools 36.0.0 درکار ہیں۔ src/android میں Gradle wrapper سے testDebugUnitTest، verifyRulesCoverage، assembleRelease اور lintRelease چلائیں؛ Windows پر gradlew.bat استعمال کریں۔ مقامی SDK راستہ یا نجی دستخطی کلید شائع نہ کریں۔ آپ کے بلڈ کا سرٹیفکیٹ سرکاری APK سے مختلف ہو سکتا ہے۔
