# Lume Órbita — हिन्दी

QA: [0.4.0](../../qa/i18n-validation.md)

Android TV और Google TV 11 या बाद के संस्करण के लिए मूल लॉन्चर। सभी टीवी मॉडल प्रमाणित नहीं हैं; Home और स्टैंडबाय का व्यवहार निर्माता पर निर्भर करता है।

## भाषा और नियंत्रण

सेटिंग > भाषा में स्वचालित चयन टीवी की समर्थित भाषा अपनाता है। समर्थन न मिलने पर en-US उपयोग होती है। आप भाषा स्वयं भी चुन सकते हैं; केवल ऐप की भाषा बदलती है, टीवी की नहीं। हिन्दी का टैग hi-IN है।

तीर से आगे बढ़ें, OK से चुनें और वापस से लौटें। ऐप पर OK दबाए रखने से कार्रवाइयाँ खुलती हैं। लाइब्रेरी में OK से पसंदीदा जोड़ें या हटाएँ; मेन्यू के स्थान बदलें विकल्प से क्रम बदलें। चयन और पसंदीदा डिवाइस पर सहेजे जाते हैं। प्लेटफ़ॉर्म की सामग्री और ऐप नाम संबंधित प्रकाशकों से आते हैं।

## रूप और स्क्रीनसेवर

सिनेमा मोड केवल लॉन्चर को मंद करता है। वैकल्पिक समय-सारणी टीवी के स्थानीय समय में रात 8 से सुबह 6 बजे तक है; टीवी की तस्वीर की सेटिंग नहीं बदलती। ऑफ़लाइन प्रक्रियात्मक कला उपलब्ध है। ऑनलाइन तस्वीरें ऐप की मेमोरी में रहती हैं, डिस्क कैश में नहीं। तस्वीरों के श्रेय सेटिंग में देखें। Android दूसरे ऐप्स के स्क्रीनसेवर और स्लीप को नियंत्रित करता है।

## इंस्टॉल करना और वापस लौटना

सिर्फ़ अधिकृत ADB कनेक्शन से APK इंस्टॉल करें। पहले वाला Home घटक दर्ज करें, इंस्टॉल करने के बाद फिर जाँचें और अनपेक्षित बदलाव होने पर रुकें। अपडेट के लिए वही पैकेज और प्रमाणपत्र आवश्यक हैं; फ़र्क होने पर डेटा मिटाकर या अनइंस्टॉल करके बाधा न हटाएँ। ऐप इंस्टॉल करना उसे अपने आप डिफ़ॉल्ट Home नहीं बनाता।

पहले ऐप जाँचें, फिर आधिकारिक Home चयन से उसे चुनें। पुराना संगत लॉन्चर इंस्टॉल रखें। Lume हटाने से पहले किसी दूसरे काम कर रहे Home को चुनें और रिमोट से जाँचें। root, फ़र्मवेयर बदलाव या सिस्टम ऐप हटाना ज़रूरी नहीं है।

## बिल्ड, लाइसेंस और जाँच

अनुवाद की JSON फ़ाइलें बदलने पर पहले प्रोजेक्ट की मूल निर्देशिका से संसाधन दोबारा बनाएँ और जाँचें। इसके लिए Python 3.10 या बाद का संस्करण चाहिए:

```sh
python tools/build_locale_resources.py
python tools/verify_locales.py
```

JDK 17, Android SDK 35 और Build Tools 36.0.0 चाहिए। src/android में Gradle wrapper से testDebugUnitTest, verifyRulesCoverage, assembleRelease और lintRelease चलाएँ; Windows पर gradlew.bat उपयोग करें। स्थानीय SDK पथ और हस्ताक्षर की निजी कुंजी साझा न करें। अपने बिल्ड का प्रमाणपत्र आधिकारिक APK से अलग हो सकता है।
