# Lume Órbita — پنجابی (شاہ مکھی)

QA: [0.4.0](../../qa/i18n-validation.md) · [0.4.1](../../qa/konka-041-validation.md) · [0.4.2](../../qa/clock-locale-042.md)

Android TV تے Google TV 11 یا اگلے نسخیاں لئی اصل لانچر۔ سارے ماڈلاں دی میل کھان دی پکی جانچ نئیں ہوئی؛ Home تے سٹینڈبائی توں مُڑن دا ڈھنگ ٹی وی بناؤن والے اُتے اے۔

## بولی تے ریموٹ

سیٹنگاں > بولی وچ خودکار چُون ٹی وی دی معاون بولی اپناؤندی اے؛ اوہ نہ ملے تاں en-US ورتی جاندی اے۔ تسی آپ وی چُن سکدے او۔ صرف ایپ دی بولی بدلدی اے، ٹی وی دے سسٹم دی نئیں۔ شاہ مکھی پنجابی دا ٹیگ pnb-Arab-PK اے تے لکھت سجے توں کھبے اے۔

تیراں نال چلو، OK نال چُنو تے پچھے والے بٹن نال مُڑو۔ ایپ اُتے OK دبی رکھن نال کماں دا مینیو کھُلدا اے۔ لائبریری وچ OK نال من پسند پاؤ یا کڈھو؛ تھاں بدلو نال ترتیب بدلو۔ چُون اپنے آلے اُتے سانبھی رہندی اے۔ ایپاں دے ناں تے سانجھا مواد اوہناں دے ناشر دیندے نیں۔

## روپ تے سکرین سیور

سنیما موڈ صرف لانچر دی لو مدھم کردا اے۔ مرضی دی ویلے والی ترتیب ٹی وی دے مقامی ویلے وچ رات 8 توں سویرے 6 وجے تک اے؛ ٹی وی دی تصویر دیاں سیٹنگاں نئیں بدلدیاں۔ آف لائن الگورتھم نال بنیا فن ملدا اے۔ آن لائن تصویراں صرف ایپ دی میموری وچ رہندیاں نیں، ڈسک کیش وچ نئیں۔ سیٹنگاں وچ تصویراں دے حوالے ویکھو۔ دوجیاں ایپاں دا سکرین سیور تے ٹی وی دی نیند Android سنبھالدا اے۔

## انسٹال، تازہ کرنا تے مُڑنا

صرف اجازت والے ADB کنکشن نال APK انسٹال کرو۔ پہلاں والا Home جزو لکھ لو، انسٹال پچھوں فیر پڑتال کرو تے اچانک تبدیلی ہووے تاں رُک جاؤ۔ تازہ نسخے لئی اوہی پیکیج تے سرٹیفکیٹ لوڑیندا اے؛ دستخط دا فرق مٹاؤن لئی ڈیٹا نہ مٹاؤ تے اَن انسٹال نہ کرو۔ خالی انسٹال کرن نال ایپ ڈیفالٹ Home نئیں بن جاندی۔

پہلاں ایپ آزما لو، فیر ٹی وی دی سرکاری Home چُون وچ چُنو۔ ہور میل کھاندا لانچر انسٹال رکّھو۔ Lume کڈھن توں پہلوں ہور چلدا Home چُن کے ریموٹ نال آزما لو۔ root، فرم ویئر بدلنا یا سسٹم ایپاں مٹاؤنا لوڑیندا نئیں۔

## بِلڈ، لائسنس تے پڑتال

ترجمے دیاں JSON فائلاں بدلن پچھوں، Gradle توں پہلوں پراجیکٹ دے مُڈھلے فولڈر توں وسائل فیر بناؤ تے پڑتال کرو۔ Python 3.10 یا نواں نسخہ چاہیدا اے:

```sh
python tools/build_locale_resources.py
python tools/verify_locales.py
```

JDK 17، Android SDK 35 تے Build Tools 36.0.0 چاہیدے نیں۔ src/android وچ Gradle wrapper نال testDebugUnitTest، verifyRulesCoverage، assembleRelease تے lintRelease چلاؤ؛ Windows اُتے gradlew.bat ورتو۔ مقامی SDK دا راہ یا دستخط دی نجی کُنجی شائع نہ کرو۔ تہاڈی بِلڈ دا سرٹیفکیٹ سرکاری APK توں وکھرا ہو سکدا اے۔
