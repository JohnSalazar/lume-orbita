# Lume Órbita — বাংলা

QA: [0.4.0](../../qa/i18n-validation.md)

Android TV ও Google TV 11 বা পরের সংস্করণের জন্য মৌলিক লঞ্চার। সব মডেলের সামঞ্জস্য প্রত্যয়িত নয়; Home ও স্ট্যান্ডবাই থেকে ফেরার আচরণ নির্মাতার ওপর নির্ভর করে।

## ভাষা ও নিয়ন্ত্রণ

সেটিংস > ভাষায় স্বয়ংক্রিয় নির্বাচন টিভির সমর্থিত ভাষা অনুসরণ করে; সমর্থন না থাকলে en-US ব্যবহার করে। নিজেও ভাষা বেছে নিতে পারেন। এতে শুধু অ্যাপের ভাষা বদলায়, টিভির সিস্টেম ভাষা নয়। বাংলার ট্যাগ bn-BD।

তীর দিয়ে চলুন, OK দিয়ে বাছুন এবং পেছনের বোতামে ফিরুন। অ্যাপের ওপর OK চেপে রাখলে কাজের মেনু খোলে। লাইব্রেরিতে OK দিয়ে পছন্দে যোগ বা সরানো যায়; সরান বিকল্পে ক্রম বদলান। নির্বাচন ডিভাইসে সংরক্ষিত থাকে। অ্যাপের নাম ও শেয়ার করা কনটেন্ট প্রকাশকের কাছ থেকে আসে।

## চেহারা ও স্ক্রিনসেভার

সিনেমা মোড শুধু লঞ্চারের আলো কমায়। ঐচ্ছিক সময়সূচি টিভির স্থানীয় সময়ে রাত ৮টা থেকে সকাল ৬টা; টিভির ছবির সেটিং বদলায় না। অফলাইনে অ্যালগরিদমে তৈরি শিল্প দেখা যায়। অনলাইন ছবি শুধু অ্যাপের মেমরিতে থাকে, ডিস্ক ক্যাশে নয়। ছবির স্বীকৃতি সেটিংসে রয়েছে। অন্য অ্যাপের স্ক্রিনসেভার ও টিভির ঘুম Android নিয়ন্ত্রণ করে।

## ইনস্টল, হালনাগাদ ও ফিরে যাওয়া

কেবল অনুমোদিত ADB সংযোগ দিয়ে APK ইনস্টল করুন। আগের Home কম্পোনেন্ট লিখে রাখুন, ইনস্টলের পরে আবার যাচাই করুন এবং অপ্রত্যাশিত পরিবর্তন হলে থামুন। হালনাগাদের প্যাকেজ ও স্বাক্ষরের সনদ একই হতে হবে। স্বাক্ষরের অমিল পাশ কাটাতে ডেটা মুছবেন না বা আনইনস্টল করবেন না। ইনস্টল করলেই এটি ডিফল্ট Home হয় না।

আগে অ্যাপ পরীক্ষা করুন, পরে টিভির আনুষ্ঠানিক Home নির্বাচনে বাছুন। অন্য সামঞ্জস্যপূর্ণ লঞ্চার ইনস্টল রাখুন। Lume সরানোর আগে অন্য কার্যকর Home বেছে রিমোট দিয়ে যাচাই করুন। root, ফার্মওয়্যার পরিবর্তন বা সিস্টেম অ্যাপ মোছার দরকার নেই।

## বিল্ড, লাইসেন্স ও পরীক্ষা

অনুবাদের JSON ফাইল বদলালে Gradle চালানোর আগে প্রকল্পের মূল ফোল্ডার থেকে রিসোর্স আবার তৈরি ও যাচাই করুন। Python 3.10 বা পরের সংস্করণ প্রয়োজন:

```sh
python tools/build_locale_resources.py
python tools/verify_locales.py
```

JDK 17, Android SDK 35 এবং Build Tools 36.0.0 প্রয়োজন। src/android থেকে Gradle wrapper দিয়ে testDebugUnitTest, verifyRulesCoverage, assembleRelease ও lintRelease চালান; Windows-এ gradlew.bat ব্যবহার করুন। স্থানীয় SDK পাথ বা ব্যক্তিগত স্বাক্ষর কী প্রকাশ করবেন না। নিজের বিল্ডের সনদ আনুষ্ঠানিক APK থেকে আলাদা হতে পারে।
