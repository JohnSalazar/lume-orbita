# Lume Órbita — मराठी

QA: [0.4.0](../../qa/i18n-validation.md)

Android TV आणि Google TV 11 किंवा नंतरच्या आवृत्त्यांसाठी मूळ लाँचर. सर्व मॉडेलची सुसंगतता प्रमाणित केलेली नाही; Home आणि स्टँडबायमधून परतण्याचे वर्तन निर्मात्यावर अवलंबून असते.

## भाषा आणि नियंत्रण

सेटिंग्ज > भाषा मधील स्वयंचलित निवड टीव्हीच्या समर्थित भाषेनुसार होते. ती उपलब्ध नसल्यास en-US वापरली जाते. भाषा स्वतःही निवडता येते; फक्त अॅपची भाषा बदलते, टीव्हीची नाही. मराठीचा टॅग mr-IN आहे.

बाणांनी फिरा, OK ने निवडा आणि मागे दाबून परत या. अॅपवर OK दाबून ठेवल्यास कृतींचा मेनू उघडतो. लायब्ररीत OK ने आवडत्यांमध्ये जोडा किंवा काढा; जागा बदला पर्यायाने क्रम बदला. निवडी उपकरणावर जतन होतात. अॅप्सची नावे आणि शेअर केलेली सामग्री संबंधित प्रकाशक पुरवतात.

## दृश्यरूप आणि स्क्रीनसेव्हर

सिनेमा मोड फक्त लाँचरचा प्रकाश कमी करतो. ऐच्छिक वेळापत्रक टीव्हीच्या स्थानिक वेळेनुसार रात्री 8 ते सकाळी 6 असे आहे; टीव्हीच्या चित्राची सेटिंग्ज बदलत नाहीत. ऑफलाइन अल्गोरिदमने तयार केलेली कला उपलब्ध आहे. ऑनलाइन चित्रे फक्त अॅपच्या मेमरीत राहतात, डिस्क कॅशमध्ये नाहीत. चित्रांचे श्रेय सेटिंग्जमध्ये पाहा. इतर अॅप्समधील स्क्रीनसेव्हर आणि टीव्हीची झोप Android नियंत्रित करतो.

## इंस्टॉल, अपडेट आणि पुनर्स्थापना

फक्त अधिकृत ADB जोडणीवरून APK इंस्टॉल करा. आधीचा Home घटक नोंदवा, इंस्टॉलनंतर पुन्हा तपासा आणि अनपेक्षित बदल झाल्यास थांबा. अपडेटसाठी तेच पॅकेज आणि प्रमाणपत्र आवश्यक आहे; स्वाक्षरीतील फरक टाळण्यासाठी डेटा पुसू नका किंवा अनइंस्टॉल करू नका. इंस्टॉल केल्यानेच अॅप डीफॉल्ट Home होत नाही.

आधी अॅप तपासा, नंतर टीव्हीच्या अधिकृत Home निवडीतून निवडा. दुसरा सुसंगत लाँचर इंस्टॉल ठेवा. Lume काढण्यापूर्वी दुसरे चालणारे Home निवडा आणि रिमोटने तपासा. root, फर्मवेअरमध्ये बदल किंवा सिस्टीम अॅप्स काढणे आवश्यक नाही.

## बिल्ड, परवाना आणि चाचणी

भाषांतराच्या JSON फाइल्स बदलल्यानंतर Gradle चालवण्याआधी प्रकल्पाच्या मूळ फोल्डरमधून संसाधने पुन्हा तयार करून तपासा. Python 3.10 किंवा नंतरची आवृत्ती आवश्यक आहे:

```sh
python tools/build_locale_resources.py
python tools/verify_locales.py
```

JDK 17, Android SDK 35 आणि Build Tools 36.0.0 आवश्यक आहेत. src/android मध्ये Gradle wrapper वापरून testDebugUnitTest, verifyRulesCoverage, assembleRelease आणि lintRelease चालवा; Windows वर gradlew.bat वापरा. स्थानिक SDK पथ किंवा खासगी स्वाक्षरीची किल्ली प्रकाशित करू नका. तुमच्या बिल्डचे प्रमाणपत्र अधिकृत APK पेक्षा वेगळे असू शकते.
