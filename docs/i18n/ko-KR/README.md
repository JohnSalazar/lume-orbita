# lume órbita — 한국어 안내

QA: [0.4.0](../../qa/i18n-validation.md) · [0.4.1](../../qa/konka-041-validation.md) · [0.4.2](../../qa/clock-locale-042.md)

lume órbita는 Android TV와 Google TV 11 이상을 위한 오리지널 런처입니다. Kotlin과 네이티브 Views를 사용하며 루팅이 필요 없습니다. 앱 목록, 순서를 바꿀 수 있는 즐겨찾기, 이어서 시청·추천, 유리 느낌의 외관, 시네마 모드, 30가지 배경, 화면 보호기를 제공합니다. 기능 지원은 제조사와 기기에 따라 다릅니다.

## 언어

설정에서 언어를 여세요. 자동은 TV 언어 목록 중 처음으로 지원되는 언어를 사용하며, 일치하는 언어가 없으면 영어(미국)를 선택합니다. 수동 선택은 저장되며 이 런처에만 적용됩니다. TV 전체의 언어를 바꾸지 않습니다. 지역 변형을 포함한 21가지 언어를 지원합니다. 앱 이름과 플랫폼이 제공하는 작품명·줄거리는 원래 언어로 표시될 수 있습니다.

## 리모컨과 콘텐츠

좌우 키로 메뉴, 이어서 시청, 추천, 시네마 모드 사이를 이동합니다. 제목에 초점이 있으면 마지막으로 선택한 카드와 세부 정보를 미리 보여 주지만 실제 초점은 제목에 남습니다. 아래 또는 OK로 카드에 들어가고 위로 제목에 돌아옵니다. 즐겨찾기에서는 OK로 앱을 열고, OK를 길게 눌러 작업을 표시합니다. 앱 목록의 OK는 즐겨찾기 추가·제거입니다. 이동 중에는 좌우로 조정하고 OK로 저장하며 뒤로 누르면 취소합니다.

콘텐츠와 시청 진행 정보는 플랫폼이 Android에 공유한 자료를 사용합니다. 선택 권한인 READ_TV_LISTINGS는 TV에서 허용해야 합니다. 권한이나 공유 데이터가 없으면 콘텐츠가 비어 있을 수 있습니다. 스트리밍 계정에 접근하지 않습니다. 실행 가능한 앱만 표시하며 백그라운드 서비스나 비활성 컴포넌트를 앱으로 가져오지 않습니다.

## 설치와 홈 화면

TV의 운영체제, 공식 디버깅 방법, 현재 홈 앱을 먼저 확인하세요. 제공된 APK의 SHA-256을 배포 해시와 비교하세요. 아래의`SERIAL`과`LUME.apk`는 실제 기기 식별자와 파일 이름으로 바꿔야 합니다.

`adb install -r` 전후에 선택된 기본 홈 앱과 Home 버튼이 여는 화면을 기록하고 확인하세요. 일부 기기는 업데이트 후 기본 홈 선택이 바뀔 수 있으므로 유지된다고 가정하지 마세요. 다른 정상적인 런처를 사용할 수 있게 유지하고, 필요하면 Android 선택 화면에서 원래 선택으로 되돌리세요.

```sh
adb devices
adb -s SERIAL install -r LUME.apk
adb -s SERIAL shell am start -n br.com.lume.launcher/.LauncherActivity
```

먼저 일반 앱으로 시험한 다음 Lume 설정이나 Android 기본 앱 설정에서 홈을 선택하세요. 선택 메뉴는 펌웨어에 따라 다릅니다. 평가 중에는 다른 호환 런처를 유지하고 Home, 뒤로, 대기 모드 복귀를 각각 확인하세요. 기본 홈 설정과 대기 모드에서 돌아올 위치는 서로 다른 동작입니다.

복구하려면 다른 정상적인 홈을 먼저 선택한 뒤 Lume 제거를 검토하세요. 유일한 홈이나 시스템 컴포넌트를 제거하지 마세요. 업데이트에는 같은 패키지와 서명이 필요합니다. 직접 빌드하면 공식 APK와 다른 키가 생성될 수 있습니다. 서명 오류를 우회하려고 데이터를 지우지 마세요.

## 외관·시네마 모드·화면 보호기

투명도, 반사, 애니메이션, 경량 모드와 배경을 조절할 수 있습니다. 시네마 모드는 런처의 밝기·색감과 효과만 바꾸며 TV 화질 설정은 변경하지 않습니다. 선택 가능한 예약 시간은 현지 시간 20:00–06:00입니다. 수동 전환은 예약을 끕니다.

화면 보호기는 무료 온라인 풍경이나 오프라인 절차적 생성 아트를 표시합니다. 사진은 RAM에만 보관하고 TV 저장소에 쓰지 않습니다. 프로세스가 종료되면 다시 불러와야 합니다. 시작 지연, 이미지 간격, 어둡기와 시계를 설정할 수 있습니다. 런처 내 유휴 화면과 다른 앱·TV 절전 중 Android가 관리하는 화면은 별개입니다. 방향키, OK 또는 뒤로 누르면 종료됩니다. 이미지 출처에는 작가, 원본, 라이선스와 표시 과정의 변경 사항이 포함됩니다.

Google Play, 네트워크 설정과 HDMI 입력은 기기의 시스템 기능에 의존합니다. 호환성과 설치 확인은 스토어가 담당하며 런처는 APK를 자동으로 다운로드하거나 설치하지 않습니다.

## 빌드와 검증

JDK 17, Android SDK Platform 35, Build Tools 36.0.0이 필요합니다. 자신의`JAVA_HOME`, `ANDROID_HOME` 또는 추적되지 않는`local.properties`를 설정하고 SDK 라이선스에 동의하세요. Gradle은 wrapper로 받습니다.

번역 JSON을 수정한 뒤에는 저장소 루트에서 XML 리소스를 다시 생성한 다음 검증과 Gradle 빌드를 실행하세요.

```sh
python tools/build_locale_resources.py
cd src/android
./gradlew --no-daemon --max-workers=1 testDebugUnitTest verifyRulesCoverage assembleRelease lintRelease
```

Windows PowerShell에서는`./gradlew` 대신`.\gradlew.bat`를 사용하세요. APK 경로는`src/android/app/build/outputs/apk/release/app-release.apk`입니다. 저장소 루트에서는 다음 명령을 실행할 수 있습니다.

```sh
python tools/verify_locales.py
python tools/verify_locales.py --self-check
```

정적 검증은 리소스와 형식을 확인합니다. self-check는 검증 도구 자체의 테스트입니다. 21개 언어의 실제 UI 시험이나 원어민 교정을 대체하지 않습니다. 로직 커버리지가 모든 TV UI의 무오류를 뜻하지 않습니다.[국제화 테스트 계획](../../qa/i18n-test-plan.md)을 참고하세요.

## 개인정보와 라이선스

자체 백엔드나 원격 측정은 없습니다. 즐겨찾기, 외관, 언어는 앱의 비공개 설정에 저장합니다. 온라인 이미지는 HTTPS 요청을 사용합니다. RAM 캐시 한도는 앱 전체 메모리 한도가 아닙니다. 시청 기록, 디버그 자료나 서명 키를 공개하지 마세요.

오리지널 코드는[MIT](../../../LICENSE) 라이선스입니다. 사진, 의존 라이브러리, 도구와 상표는 각각의 권리를 유지합니다.[제3자 고지](../../../THIRD_PARTY_NOTICES.md)를 확인하세요. 번역은 원본 법률 문서를 대체하지 않습니다.

## GitHub를 통한 업데이트 (0.4.3+)

**앱 정보**에서 **업데이트 확인**을 선택하세요. GitHub 확인은 클릭할 때만 이루어지며 주기적으로 자동 확인하지 않습니다. 호환되는 새 버전이 있으면 **업데이트 다운로드**를 선택하세요. 다운로드 검증 후 **업데이트 설치**를 선택하면 Android에서 설치 확인을 요청합니다. Android에서 권한을 요구하면 **이 출처 허용**을 열고 Android 설정에서 직접 Lume를 허용한 다음 돌아와 확인하세요. Lume가 이 권한을 자동으로 부여하지는 않습니다. 같은 패키지와 서명 인증서로 업데이트하면 설정이 유지됩니다. 업데이트를 위해 Lume를 제거하지 마세요. 이후 Home을 확인하세요. TV가 선택을 변경했다면 **홈 화면 선택 확인**에서 시스템 설정을 열어 직접 선택할 수 있습니다.
