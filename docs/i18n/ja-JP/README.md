# lume órbita — 日本語ガイド

QA: [0.4.0](../../qa/i18n-validation.md) · [0.4.1](../../qa/konka-041-validation.md) · [0.4.2](../../qa/clock-locale-042.md)

lume órbitaはAndroid TVおよびGoogle TV 11以降向けのオリジナルランチャーです。KotlinとネイティブViewsを使用し、rootは不要です。アプリ一覧、並べ替え可能なお気に入り、視聴の続き・おすすめ、ガラス調の外観、シネマモード、30種類の背景、スクリーンセーバーを備えます。利用できる機能はメーカーや機種によって異なります。

## 言語

設定の「言語」を開いてください。自動ではテレビの言語リストから最初に対応する言語を選び、該当しない場合は英語（米国）を使います。手動選択は保存され、このランチャーだけに適用されます。テレビ全体の言語は変更しません。地域別の設定を含む21言語に対応します。アプリ名や配信サービスが提供する作品名・あらすじは元の言語のままの場合があります。

## リモコン操作とコンテンツ

左右キーでメニュー、視聴を続ける、おすすめ、シネマモードへ移動します。見出しにフォーカスがある間は、前回選んだカードと詳細をプレビューしますが、実際のフォーカスは見出しに残ります。下キーまたはOKでカードへ入り、上キーで見出しへ戻ります。お気に入りではOKでアプリを開き、OK長押しで操作メニューを表示します。アプリ一覧のOKはお気に入りへの追加・削除です。移動中は左右キーで調整し、OKで保存、戻るでキャンセルします。

作品や進捗は各サービスがAndroidに共有した情報です。任意のREAD_TV_LISTINGS権限はテレビ側で許可します。権限や共有データがなければ一覧は空になることがあります。配信アカウントにはアクセスしません。起動できるアプリだけを一覧にし、サービスや無効なコンポーネントを勝手に取り込みません。

## インストールとホーム画面

テレビのOS、公式のデバッグ方法、現在のホームアプリを確認してください。配布APKは公開されたSHA-256と照合します。以下の`SERIAL`と`LUME.apk`は実際の端末識別子・ファイル名に置き換えてください。

`adb install -r` の前後で、既定のホームアプリとHomeボタンの移動先を記録・確認してください。端末によっては更新でホームの選択が変わる場合があり、保持されるとは限りません。別の正常なランチャーを利用できる状態に保ち、必要ならAndroidの選択画面から元に戻してください。

```sh
adb devices
adb -s SERIAL install -r LUME.apk
adb -s SERIAL shell am start -n br.com.lume.launcher/.LauncherActivity
```

最初は通常のアプリとして試し、必要ならLumeの設定またはAndroidの既定アプリ設定からホームを選びます。選択方法はファームウェア次第です。評価中は別の互換ランチャーを残し、Home、戻る、待機復帰を個別に確認してください。ホームの既定設定と待機からの復帰先は別の動作です。

元に戻すときは、別の正常なホームを選んでからLumeの削除を検討します。唯一のホームやシステムコンポーネントを削除しないでください。更新には同じパッケージと署名が必要です。自分でビルドした鍵は公式APKと異なる場合があります。署名エラーを回避するためにデータを消すことは勧めません。

## 外観・シネマモード・スクリーンセーバー

透明度、反射、アニメーション、軽量モード、背景を調整できます。シネマモードはランチャーの明るさ・色合いと視覚効果だけを変え、テレビの画質設定を変更しません。任意のスケジュールは現地時刻20:00–6:00です。手動切り替えはスケジュールをオフにします。

スクリーンセーバーでは無料のオンライン風景やオフラインの自動生成アートを表示します。写真はメモリだけに保持し、テレビのストレージには保存しません。プロセス終了後は再読み込みが必要です。開始までの時間、切り替え間隔、暗さ、時計を設定できます。ランチャー内の待機表示と、他のアプリ・テレビのスリープ時にAndroidが管理する表示は別です。方向キー、OK、戻るで終了します。画像のクレジットには作者、出典、ライセンス、表示上の変更を掲載します。

Google Play、ネットワーク設定、HDMI入力は機器のシステム機能に依存します。互換性やインストール確認はストアが担当し、ランチャーはAPKを自動取得・インストールしません。

## ビルドと検証

JDK 17、Android SDK Platform 35、Build Tools 36.0.0が必要です。自分の`JAVA_HOME`、`ANDROID_HOME`または未追跡の`local.properties`を設定し、SDKのライセンスに同意してください。Gradleはwrapperから取得します。

翻訳JSONを変更したら、リポジトリのルートでXMLリソースを再生成してから、検証とGradleビルドを実行してください。

```sh
python tools/build_locale_resources.py
cd src/android
./gradlew --no-daemon --max-workers=1 testDebugUnitTest verifyRulesCoverage assembleRelease lintRelease
```

Windows PowerShellでは`./gradlew`を`.\gradlew.bat`に置き換えます。APKは`src/android/app/build/outputs/apk/release/app-release.apk`です。リポジトリのルートでは次を実行できます。

```sh
python tools/verify_locales.py
python tools/verify_locales.py --self-check
```

静的検証はリソースと書式を確認します。self-checkは検証ツール自体のテストです。21言語の実画面テストや母語話者による校閲の代わりにはなりません。ロジックのカバレッジは全テレビのUIが正しい保証ではありません。[国際化テスト計画](../../qa/i18n-test-plan.md)も参照してください。

## プライバシーとライセンス

独自のバックエンドやテレメトリーはありません。お気に入り、外観、言語などはアプリのプライベート設定に保存します。オンライン画像にはHTTPS接続を使います。RAMキャッシュの上限はアプリ全体のメモリ上限ではありません。視聴履歴、デバッグ記録、署名鍵を公開しないでください。
