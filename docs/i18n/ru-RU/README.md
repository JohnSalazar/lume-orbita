# lume órbita — руководство на русском

QA: [0.4.0](../../qa/i18n-validation.md)

lume órbita — оригинальный лаунчер для Android TV и Google TV 11 и новее. Написан на Kotlin с нативными Views, не требует root. Включает список приложений, упорядочиваемое избранное, продолжение просмотра и рекомендации, стеклянный интерфейс, кинорежим, 30 фонов и заставку. Возможности зависят от модели и производителя.

## Язык

Откройте раздел «Язык» в настройках. Автоматический режим выбирает первый поддерживаемый язык из списка телевизора. Если подходящего нет, используется английский (США). Ручной выбор сохраняется и меняет только язык лаунчера, а не системы. Поддерживается 21 язык с региональными вариантами. Названия приложений, произведений и описания от платформ могут остаться на исходном языке.

## Пульт и контент

Влево/вправо перемещают фокус между меню, продолжением просмотра, рекомендациями и кинорежимом. На заголовке показывается увеличенная последняя карточка с описанием, но реальный фокус остаётся на заголовке. Вниз или OK переходят к карточке, нажатие вверх возвращает фокус на заголовок. В избранном OK открывает приложение, долгое нажатие показывает действия. В списке приложений OK добавляет или убирает избранное. При перемещении стрелки меняют позицию, OK сохраняет, Назад отменяет.

Контент и прогресс зависят от сведений, которыми платформы делятся с Android. Необязательное разрешение READ_TV_LISTINGS выдаётся на телевизоре. Без него или без данных список может быть пустым. Лаунчер не получает доступ к аккаунтам стриминга. В каталоге только запускаемые приложения, а не фоновые службы и отключённые компоненты.

## Установка и главный экран

Сначала проверьте систему телевизора, официальный способ отладки и текущий главный экран. Сверьте SHA-256 APK с хешем выпуска. В примере замените `SERIAL` и `LUME.apk` на идентификатор своего устройства и имя файла:

До и после `adb install -r` запишите и проверьте выбранный главный экран по умолчанию и действие кнопки Home. На некоторых устройствах обновление может изменить этот выбор; не считайте его сохранение гарантированным. Оставьте доступным другой рабочий лаунчер и при необходимости восстановите выбор через системный интерфейс Android.

```sh
adb devices
adb -s SERIAL install -r LUME.apk
adb -s SERIAL shell am start -n br.com.lume.launcher/.LauncherActivity
```

Сначала проверьте обычный запуск. Затем при желании выберите Lume главным экраном через его настройки или системный выбор приложений по умолчанию. Возможность зависит от прошивки. Во время оценки оставьте другой совместимый лаунчер и отдельно проверьте Home, Назад и выход из ожидания. Главный экран по умолчанию и возобновление после ожидания — разные механизмы.

Для возврата сначала выберите другой работающий главный экран, затем решайте, удалять ли Lume. Не удаляйте единственный главный экран или системные компоненты. Обновление требует прежних пакета и подписи. Локальная сборка может иметь другой ключ; не стирайте данные лишь для обхода несовместимой подписи.

## Внешний вид, кинорежим и заставка

Доступны прозрачность, отражения, анимация, облегчённый режим и фоны. Кинорежим меняет яркость, оттенок и эффекты только лаунчера, не настройки изображения телевизора. Необязательное расписание действует 20:00–06:00 по местному времени. Ручное переключение выключает расписание.

Заставка показывает бесплатные онлайн-пейзажи или процедурную графику без сети. Фотографии хранятся только в RAM, не записываются в хранилище телевизора и после завершения процесса загружаются заново. Настраиваются задержка запуска, смена изображений, затемнение и часы. Заставка внутри лаунчера отличается от заставки, которой Android управляет в других приложениях и при сне TV. Стрелки, OK или Назад завершают показ. В сведениях об изображениях указаны авторы, оригиналы, лицензии и изменения отображения.

Google Play, сетевые настройки и HDMI зависят от системных возможностей устройства. Совместимость и подтверждение установки обеспечивает магазин; лаунчер сам не скачивает и не устанавливает APK.

## Сборка и проверка

Нужны JDK 17, Android SDK Platform 35 и Build Tools 36.0.0. Настройте свои `JAVA_HOME`, `ANDROID_HOME` или неотслеживаемый `local.properties`, примите лицензии SDK. Gradle предоставляется wrapper:

После изменения JSON-каталогов заново сгенерируйте XML-ресурсы из корня репозитория, затем выполните проверки и сборку Gradle:

```sh
python tools/build_locale_resources.py
cd src/android
./gradlew --no-daemon --max-workers=1 testDebugUnitTest verifyRulesCoverage assembleRelease lintRelease
```

В Windows PowerShell замените `./gradlew` на `.\gradlew.bat`. APK появится в `src/android/app/build/outputs/apk/release/app-release.apk`. Из корня репозитория доступны:

```sh
python tools/verify_locales.py
python tools/verify_locales.py --self-check
```

Статическая проверка проверяет ресурсы и форматирование; self-check проверяет сам инструмент. Это не заменяет реальные UI-тесты 21 языка и вычитку носителями. Покрытие логики не гарантирует отсутствие ошибок интерфейса на всех TV. См. [план тестирования локализации](../../qa/i18n-test-plan.md).

## Приватность и лицензия

Собственного сервера и телеметрии нет. Избранное, оформление и язык хранятся в приватных настройках приложения. Онлайн-изображения используют HTTPS. Лимит RAM-кэша не равен общей памяти приложения. Не публикуйте историю просмотра, диагностические записи или ключи подписи.
